**Sobre o repositório:**
- Código de extensão de Google Chrome para acessar legislação de maneira rápida.
- Desenvolvido com auxílio de IA, a partir da ideia do @AdvDoHardware.
- As ferramentas desenvolvidas com IA podem conter erros. Verifique o código e utilize por sua conta e risco.

**Utilizando no Google Chrome:**
1. Salve todos os arquivos na mesma pasta.
2. Abra o Google Chrome e acesse chrome://extensions.
3. Ative a chave Modo do desenvolvedor no canto superior direito.
4. Clique em Carregar sem compactação e selecione a pasta.
   
**Funcionalidades:**
- Busca por popup (atalho ALT+L).
- Busca por omnibox (barra do navegador com palavra-chave 'lei').
- Busca de texto selecionado (menu de contexto e botão flutuante).
- Vários padrões de pesquisa reconhecidos.
